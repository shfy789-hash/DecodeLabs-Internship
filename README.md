# DecodeLabs Internship Projects

Welcome to my repository for the DecodeLabs internship assignments. This repository contains various security and cryptography implementation projects developed during the program.

## Projects Included

* **Caesar Cipher Encryption and Decryption**
  * A Python script implementing classical Caesar cipher logic for shifting text characters to secure messages.
  
* **Password Strength Checker**
  * A Python utility designed to analyze password complexity, verifying criteria such as length, character variation, and overall strength metrics.
